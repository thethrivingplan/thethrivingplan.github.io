How to choose a code

If you want a code at all, pick a sentence from a private memory, in your own exact words — and let length do the work. Wanting one is the only reason to have one.

Read the rest before you forge
  • Length over cleverness. A longer plain sentence beats a short, tricky string. Say it the way you would actually say it.
  • Never a password used anywhere else. If you keep a code, keep it separate — it is a personal extra for you alone, not a login, not a variation of one, and not proof that a name is yours.
  • If you use it for yourself, paste it — never retype it. One different mark makes a different fingerprint, and a retyped code will eventually drift. You never need to paste it at a table to sit or vote — sitting down and voting from your device is what claims your seat.
  • If you want to keep it, give it a home. Your password manager is a good one. This page keeps nothing, so anything you want to keep is yours to save — and skipping it costs you nothing at any table.
