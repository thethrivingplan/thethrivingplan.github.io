Your Days

Your calendar of days. Each day is a hub: the events in it, the plain tasks it holds, and whatever else is happening — all in one place. Every task is paired with what you need to do it, and a day only counts as ready when everything in it is ready: events set, tasks checked, tools in hand.

Plan a day

The starter list for this kind of day loads in automatically — every task with the tools and gear it takes, ready to check off as you put them in hand.

Add an event

An event lives inside its day — pick its date and it lands in that day’s hub, carrying its full planner (lists, gear, people, offers) as a branch of the day.

The List

Everything that still needs taking care of, day by day, soonest first — each day’s tasks with their tools, plus what’s open inside its events and the gear each event needs, packed or not. Tap the big box to check something off.

Gear Containers

The boxes, bags and the trailer — each one carries its own packing list of what's supposed to be inside it. This is the standard list for each container, shared by every event. Packing check-offs happen per event, on the event itself, so packing for Friday never claims Saturday is packed.

Add a container

Then add what's supposed to live inside it. It becomes available to put on any event.

Who's Got What

Open items grouped by the person they're handed to — so you can see at a glance what's covered and what nobody has yet. Handing something to someone doesn't finish it: it only counts toward ready when it's marked Done.

The Easy-to-Miss Ones

Every item flagged “commonly overlooked” that is still open, gathered from all your events in one place. This is the section that saves the night.
