Code Breaker

A hidden code of coloured pegs. You guess; the board answers with two plain facts — how many pegs are exactly right, and how many are the right colour in the wrong place. From those two numbers, logic alone can corner the code. This page teaches that logic while you play.

An homage to the classic code-deduction games — the peg-and-feedback shape documented and loved for decades, including the game known as Mastermind. The name, artwork, and peg designs here are our own; we borrow the idea because it works, and we say so.

Learn the logic

Three ideas do all the work. Everything the helper and the bot do is built from these — nothing else.

1 · What a guess can prove — tap to open or close

A guess is not really a try at winning. It is a question. The feedback is the answer, and the answer is a fact that stays true for the rest of the game. If a guess scores 0 exact and 0 near, every colour in it is proven absent — the code contains none of them, anywhere. If it scores high, some of those colours are proven present. Each guess either shrinks the truth or sharpens it; a "wrong" guess is never wasted.

2 · The consistent set — tap to open or close

Picture every code that could possibly be the hidden one. At the start that is a big crowd — with 4 pegs and 6 colours allowing repeats, 6 × 6 × 6 × 6 = 1,296 codes. After each guess, cross out every code that would not have given the feedback you actually got. What remains is the consistent set: the codes still possible. The hidden code is always inside it. When one code remains, you have not guessed the answer — you have proven it. Good play is choosing guesses that cross out the most, whichever way the feedback falls.

3 · Information per guess — tap to open or close

When the consistent set shrinks from, say, 256 codes to 32, that guess earned you 3 "bits" of information — it cut the possibilities to an eighth (256 → 128 → 64 → 32 is three halvings). This page counts the bits for every guess when the Teaching dial is up. A guess that can only shrink the set a little is a weak question, even if it happens to score well. Strong players ask strong questions.

How feedback is scored — tap to open or close

Exact (black peg): right colour, right place. Near (white peg): right colour, wrong place. Each peg in the secret can be matched only once, and exact matches are counted first — so duplicates are handled fairly: if the code holds one Ruby and your guess holds two, at most one of them can score. Feedback pegs are shown in no particular order, so they never tell you which pegs scored. That silence is the puzzle.
