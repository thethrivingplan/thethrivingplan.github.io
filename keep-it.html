Why this works

The science, in plain words — and one tap down for the fuller story.

Retrieval practice

Trying to recall an answer strengthens memory more than re-reading it. That is why every game here makes you pull the answer out — pick it, type it, match it — instead of just looking at it again. This effect is documented and strong across many studies.

The spacing effect

The same practice spread over time beats the same practice bunched together. So Keep It schedules reviews at growing gaps: later the same day → next day → 3 days → a week → 2 weeks → a month. Get one right and the gap grows; miss one and it comes back sooner.

Two honest strategies, side by side Tap to open · Tap to close
StrategyWhat it feels likeThe trade-off
Massed cramming — everything in one sittingFast and familiar right away. Feels like learning.Fades fast. Good for a test tomorrow, poor for knowing it next month.
Spacing + retrieval — short games at growing gaps (this page)Slower to feel finished. Each return is a little effortful — that effort is the mechanism.Holds far longer for the same total minutes. Needs you to come back on schedule.

Neither is magic. Spacing wins on retention in the research; cramming wins only on speed-to-first-test. Keep It is built for keeping, so it uses spacing — and shows you your own curve so you can judge it yourself.
