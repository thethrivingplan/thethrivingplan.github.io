Tournament Builder

Name it, pick a game from the shelf, pick a shape, write in the players — and get a real bracket with a table for every match. Play it out by tapping who won. That is the whole job, and this page does all of it.

Where it lives: the bracket lives on the host's device only — this device, this browser. There is no live sync between devices and no account holding it. Bring this device back and the tournament is right where you left it.

Build a tournament

Players are just names for tonight — a session name or an alias is all anyone ever needs here. Nobody needs a claimed table name, and nobody needs an account.

A match is one full game. Highest score wins the match.

One loss ends a run. The last player standing is champion. If the player count isn't a power of two (2, 4, 8, or 16), the top seeds get a bye in round one — shown honestly on the bracket, never hidden.

The order below is the seeding: player 1 is the top seed. Not sure of a name? Tap “Give me an alias” and take the one it offers — an alias is a full player here, same as any name.

Seeding so far: the order entered. If you shuffle, the bracket will say so — seeding is always labelled, never quiet.

Join a table

Every match sits at its own table with a short code, printed right on the match. Type the code here and this page seats you at that match. All you need is the code — and the alias you're playing under in that tournament.

The tournament

When a match is played, tap the winner's name on the match — tap to record the win. The bracket moves them on by itself. A result is never quietly rewritten: fix one and the record says it was corrected, out loud.

Tournaments on this device

How the bracket works — tap to open

Seeding. The order players are entered is the seeding, unless you tap shuffle — and the bracket is labelled with whichever one was used. Seed 1 meets the lowest seed, seed 2 the next lowest, the way real brackets have always been drawn.

Byes, honestly. Single elimination needs 2, 4, 8, or 16 players to fill cleanly. With any other count, the top seeds sit out round one on a bye — the bracket shows the bye as a bye, with the player already through. Nobody is quietly dropped and no fake opponent is invented.

Tables and codes. Every playable match gets its own table code. The code is how a player finds their match with the Join a table door above. Bowling tables carry the code into the game itself, because Bowling's rooms already speak table codes; for the other games, the code seats you here and the game is one tap away.

Round robin. Everybody plays everybody once. The standings count wins; when every match is in, the player on top is champion. If two or more finish level at the top, the page says so plainly — settle it with a playoff match of your own and record it as a new tournament, rather than the page pretending a tie isn't a tie.

Corrections. Tap the other name on a finished match and the page asks you to confirm before it changes anything. A confirmed change is written into the record as a correction, with the old result still visible in the log. If a later match has already been played off the old result, the page won't let the correction through until that later match is cleared — the record never contradicts itself.

Solitaire and Blackjack matches. Both are played head-to-head here: Solitaire as the same deal raced side by side (first clear, or fewest moves, wins — agree it before you start), Blackjack as a set number of hands with the bigger chip stack taking the match. The bracket only needs a winner; how you settle it at the table is yours.
